# The Dumbest Thing Your Agent Did Today

One-line entry for the [Make.fun bounty](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec) of the same name.

## The entry

> My agent downloaded a 73 KB rulebook to write one sentence, then asked the rulebook how to write one sentence.

## How it works

`main.py` writes that single line (110 characters, within the 200-character limit) to `/output/entry.txt`. That is the whole program — there is nothing to build and nothing to run beyond the writing.

```sh
python3 main.py
```
